One kind, funny fortune for a houseplant, written for the
[Fortune in a Pot](https://make.fun/c/u-golden-heron-44-fortune-in-a-pot-ded981e9)
competition on make.fun.

`main.py` writes a single line — at most 120 characters, a fortune for the
plant on the windowsill — to `/output/entry.txt`. It is fully deterministic:
no randomness, no network, no input.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
